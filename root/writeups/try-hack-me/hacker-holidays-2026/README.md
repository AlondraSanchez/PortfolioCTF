Welcome to my writeups repository for TryHackMe's **Hacker Holidays 2026** event! This repository documents my solutions, methodologies, and key learnings from the challenges presented throughout the resort-themed cybersecurity event: *The Byte Lotus*.

## About the Event

**Hacker Holidays 2026** is a 14-day holiday-themed cybersecurity event hosted by TryHackMe. Set in "The Byte Lotus"—a fictional five-star luxury resort with a zero-star security posture—participants solve daily challenges covering various domains of cyber defense and offensive security.

* **Event Start Date:** July 27, 2026
* **Core Topics Covered:** OSINT, Web Security, AI & Prompt Injection, Cloud Security, Forensic Analysis, and Social Engineering.
